핵심 변경
- 재생목록 관리의 '+ 추가'를 누르면 파일 선택창이 열립니다.
- 파일을 선택하면 별도의 두 번째 '선택한 파일을 재생목록에 추가' 버튼 없이 즉시 재생목록에 추가됩니다.
- 중복 파일은 다시 추가하지 않습니다.
- 파일 선택 취소 후 다시 '+ 추가'해도 정상적으로 다시 선택할 수 있습니다.
- 선택된 파일은 현재 재생목록과 즉시 연결됩니다.
- 기존 기본 미디어 폴더/재생목록 복원 구조는 유지합니다.
