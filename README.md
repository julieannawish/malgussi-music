# 말구씨 음악 앱

내 음악(MP3)과 영상(MP4)을 편하게 듣는 작은 음악상자 PWA. 아이폰·안드로이드 공용.

- **앱 주소**: https://julieannawish.github.io/malgussi-music/
- **현재 버전**: V4.32

## 설치
- **아이폰**: 사파리로 접속 → 공유 → 홈 화면에 추가 (자세히: `설치안내_아이폰.png`)
- **안드로이드**: 크롬으로 접속 → 설정의 "홈 화면에 설치" (자세히: `설치안내_안드로이드.png`)

## 첫 사용
1. 설정(⚙️) → 기본 미디어 폴더 선택
2. 재생목록 관리 → ＋ 추가 → 곡 선택
3. 상단 "앱에 저장됨: ○/○곡 ✓"이 초록색이면 재실행 후에도 유지됨

## 파일 구성
| 파일 | 설명 |
|---|---|
| `index.html`, `sw.js`, `manifest.webmanifest` | 앱 본체 |
| `app-icon*.png` | 앱 아이콘(192/원본/maskable) |
| `dog_default.png`, `profile_default.png` | 기본 커버·프로필 이미지 |
| `설치안내_아이폰`, `설치안내_안드로이드` (`.md`/`.png`) | 설치 매뉴얼 |

## 참고
- 버전 확인: 앱 설정 → 앱 정보
- 배포: 이 폴더를 GitHub에 push하면 GitHub Pages로 반영됨
- 상세 변경 이력은 별도 보관
