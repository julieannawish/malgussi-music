# 말구씨 음악 앱 V3.64

## 이번 버전의 핵심
- 설정에서 지정한 **기본 미디어 폴더**를 재생목록의 유일한 미디어 원본으로 사용
- 재생목록의 `＋ 추가`는 별도 파일 선택창을 띄우지 않고 저장된 기본 미디어 폴더의 파일 목록을 바로 표시
- `＋ 추가` 화면에서 선택한 파일을 `＋ 추가` 버튼으로 재생목록에 넣고 화면을 닫음
- 추가 화면을 다시 열 때 이전 선택 상태를 초기화
- 삭제 후 다시 추가해도 선택 상태가 남지 않음
- 재생목록이 비어 있으면 기본 화면은 확정된 **강아지 그림**
- MP3: 내장 앨범커버 → 없으면 **강아지 그림**
- MP4: 내장 커버 → 없으면 첫 프레임 → 실패하면 **강아지 그림**
- 아버지 프로필 이미지는 커버 대체 이미지로 사용하지 않음
- 이전/다음 버튼을 실제 재생목록 이동에 연결
- 현재 위치는 `1곡 중 2곡`처럼 현재 순번/전체 곡수로 표시
- 저장된 기본 폴더 권한이 이미 허용되어 있으면 앱 재실행 시 자동으로 원본 파일을 다시 연결
- 재생/다음/이전 버튼을 누른 시점에 저장된 폴더 권한을 다시 요청할 수 있도록 처리
- 반복 안 함을 기본값으로 유지
- 앱 버전/서비스워커 V3.64

## 기본 점검
- HTML 내부 JavaScript 전체 구문 검사 통과
- 버전 문자열/manifest/service worker 일치 확인
- `＋ 추가` → 저장된 기본 폴더 목록 표시 경로 점검
- 추가 화면 재진입 시 선택 상태 초기화 점검
- MP3/MP4 커버 fallback 규칙 점검
- 이전/다음 버튼 이벤트 연결 점검
- 앱 시작 시 저장된 DirectoryHandle 자동 복원 경로 점검
- 재생목록/현재 인덱스 저장 및 복원 경로 점검
- 압축 내부 파일 구조 점검

실제 iPhone의 Files UI와 iOS의 파일 권한 정책은 실행 환경에서 직접 조작할 수 없으므로, 마지막 기기 확인은 필요합니다.
