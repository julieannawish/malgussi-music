말구씨 음악 앱 V3.16 SMART INDEX
- V3.15 기반
- 음악 파일 본문을 앱에 저장하지 않는 순수 인덱스 방식
- 원본 연결은 여러 파일을 한 번에 선택
- 기존 인덱스와 파일을 자동 매칭
- 1차: 파일명+크기+수정일 정확 매칭
- 2차: 유일한 파일명+크기 매칭(수정일이 바뀐 경우)
- 매칭 실패한 곡만 마지막에 목록으로 표시
- 새로 선택한 음악은 인덱스만 추가
- iPhone PWA 특성상 앱 종료 후 외부 파일 접근 권한이 유지되지 않을 수 있으므로,
  이 경우 사용자가 한 번에 원본 파일들을 다시 선택해야 함
