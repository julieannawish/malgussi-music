말구씨 음악 앱 V3.32 — 음악 폴더 지정 단일화

재생목록 관리의 원본 연결 방식은 하나만 제공합니다:
- '📁 음악 폴더 지정'
- 사용자가 음악이 들어 있는 폴더를 선택하면 전체 파일을 자동 매칭합니다.
- 찾은 곡은 자동 연결합니다.
- 폴더에서 찾지 못한 곡은 재생목록 인덱스에서 자동 정리합니다.
- 개별 파일을 하나씩 선택해서 연결하는 UI는 제공하지 않습니다.
- 음악 파일 자체는 앱 저장소에 복사하지 않습니다.
- 빈 재생목록에서 처음 음악을 추가하는 기존 흐름은 유지합니다.
- iPhone PWA에서는 앱 재실행 후 외부 폴더 권한이 자동 복원되지 않을 수 있으므로, 필요할 때 재생목록 관리에서 폴더를 한 번 지정하면 전체를 다시 연결합니다.
