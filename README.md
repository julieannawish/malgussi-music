말구씨 음악 앱 V3.22 — STABLE PWA

이번 버전은 V3.21 기능을 유지하면서 기본 이미지 표시를 더 안전하게 수정했습니다.

- 강아지 기본 이미지를 외부 파일 + HTML 내부 fallback 두 겹으로 제공
- 이미지 파일 경로/캐시 문제로 깨져도 강아지 이미지 표시
- 앨범 커버가 있으면 원본 음악에서 임시 추출
- 앨범 커버가 없으면 강아지 이미지
- 음악 파일 자체는 앱 저장공간에 저장하지 않음
- 재생목록 인덱스 방식 유지
- 다중 원본 연결 유지
- iPhone 재생목록 스크롤 유지
- PWA 캐시는 HTML/manifest/SW에 network-first 적용
- PWA 시작 URL을 v3.22로 분리하여 새 버전 로딩 가능성을 높임

GitHub Pages 루트에 압축을 풀고 파일 전체를 업로드하세요.
