말구씨 음악 앱 V3.33 — iPhone 폴더 선택 안정화

V3.32에서 iPhone의 '음악 폴더 지정'을 눌러도 폴더 선택 화면이 열리지 않을 수 있는 문제를 수정했습니다.

원인:
iOS의 파일 선택기는 사용자의 탭과 연결된 동기 실행 흐름에서 열어야 합니다. 기존 코드는 폴더 선택 전에 async/await를 수행할 수 있어 iOS가 파일 선택기를 차단할 수 있었습니다.

V3.33:
- iPhone에서는 '📁 음악 폴더 지정'을 누르는 즉시 폴더 선택기를 엽니다.
- 개별 파일 연결 버튼은 없습니다.
- 폴더를 선택하면 전체 곡을 자동 매칭합니다.
- 실제 폴더에서 찾지 못한 곡은 재생목록에서 자동 정리하고 저장합니다.
- 음악 파일 자체는 앱 저장소에 복사하지 않습니다.
