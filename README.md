# 말구씨 음악앱 V3.85

재생목록 파일 선택 화면을 폴더 탐색형으로 개선한 버전입니다.

## 이번 수정
- 설정에서 지정한 기본 미디어 폴더를 재생목록 추가의 원본으로 사용합니다.
- `재생목록 관리 → ＋ 추가`에서 전용 파일 선택 화면을 엽니다.
- 기본 미디어 폴더의 하위 폴더까지 재귀적으로 탐색합니다.
- `📁 폴더`를 눌러 하위 폴더로 들어가고 `‹ 상위 폴더` 또는 상단 경로 버튼으로 이동할 수 있습니다.
- 현재 폴더의 음악/MP4 파일만 표시하고 선택할 수 있습니다.
- 선택한 파일은 원본 폴더에 복사/이동하지 않고 재생목록에서 참조합니다.
- 하위 폴더 경로(`webkitRelativePath`)를 보존하여 동일한 파일명이 다른 폴더에 있어도 구분합니다.
- iOS/PWA의 `webkitdirectory` 방식과 File System Access API 방식 모두 하위 폴더를 재귀적으로 처리합니다.
- 추가 완료 후 재생목록으로 돌아가 성공 메시지와 함께 방금 추가한 곡 위치로 자동 스크롤합니다.
- 재생목록 자체의 세로 스크롤과 순서 변경 핸들 동작을 유지합니다.

## 버전 일관성
앱 화면, JavaScript APP_VERSION, manifest, Service Worker 캐시, README를 V3.85로 통일했습니다.
