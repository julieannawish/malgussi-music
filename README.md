# 말구씨 음악앱 V3.84

재생목록 추가/스크롤 스마트 수정 및 전체 기능 회귀 점검본.

## 이번 수정
- 재생목록 관리의 `＋ 추가`는 별도 `재생목록에 추가` 선택 화면을 열며, 기본 미디어 화면 자체를 열지 않습니다.
- 선택 화면은 설정에서 지정한 기본 미디어 폴더를 읽기 전용 원본으로 사용하며, 선택한 파일을 기본 미디어 목록에 새로 넣지 않습니다.
- 기본 미디어의 원본 목록과 재생목록 데이터를 분리합니다.
- 추가 완료 후 `✓ N곡을 재생목록에 추가했습니다.` 메시지를 표시합니다.
- 추가 직후 재생목록 화면으로 돌아와 새로 추가된 첫 곡 위치로 자동 스크롤합니다.
- 방금 추가된 곡을 약 1.8초 동안 시각적으로 강조합니다.
- 재생목록 중앙 목록 영역은 독립적인 세로 스크롤 영역으로 고정합니다.
- 순서 변경은 오른쪽 `≡` 핸들에서만 동작하며 일반 목록 영역의 세로 스크롤을 방해하지 않습니다.
- 기본 미디어에 새 파일이 자동으로 재생목록에 추가되지 않는 기존 규칙을 유지합니다.
- MP3/MP4 재생, 폴더 복원, 중복 정리, 반복 재생 등 기존 기능을 유지합니다.
