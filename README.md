말구씨 음악 앱 V3.44 — MP4 작은 화면 버튼 UI 개선

V3.44에서는 MP4의 작은 화면(PiP) 기능 UI를 더 직관적으로 변경했습니다.

- 기존 큰 [작은 화면] 버튼 제거
- MP4 영상 화면의 최상단 오른쪽에 작은 화면 아이콘(↗) 배치
- 실제 PiP 지원 환경에서만 아이콘 표시
- 아이콘을 누르면 작은 화면(PiP) 전환
- 지원하지 않는 iPhone 홈 화면 PWA에서는 아이콘을 표시하지 않음
- 기존 MP3/M4A 앨범 커버 및 MP4 영상 프레임 잠금화면 artwork 유지
- 백그라운드 재생, 잠금화면 이전/재생/다음 유지
