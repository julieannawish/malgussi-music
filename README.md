말구씨 음악 앱 V3.25 — 폴더 한 번 선택 자동 연결

사용자 편의를 위해 '원본 음악 다시 연결'을 폴더 선택 방식으로 개선했습니다.

- iPhone/Safari 최신 환경에서 음악 폴더를 한 번 선택
- 선택한 폴더 안의 음악을 재생목록 파일명/크기로 자동 매칭
- 연결되지 않은 곡만 별도로 표시
- 폴더 안의 다른 음악을 재생목록에 임의로 추가하지 않음
- 이름이 중복된 파일은 잘못 연결하지 않고 확인 대상으로 남김
- 폴더 선택을 지원하지 않는 환경에서는 기존 '파일 여러 개 선택' 방식으로 자동 대체
- 음악 파일 자체는 앱 저장공간에 복사하지 않고 현재 세션에서만 원본 File 객체를 사용
- 기존 재생목록 인덱스(localStorage key)는 유지하여 기존 목록을 보존
