말구씨 음악 앱 V3.60

핵심 변경
- 재생목록을 저장하고 앱을 다시 열어도 현재 선택 곡/목록을 유지
- 저장된 앨범커버가 있으면 재실행 직후에도 표시
- 원본 파일이 연결되지 않은 상태에서 재생 버튼을 누르면 저장된 폴더 권한을 먼저 시도하고, 필요하면 iPhone 폴더 선택창을 바로 엶
- 재생목록 관리의 재생 방식 기본값은 '반복 안 함'
- 반복 안 함 / 순서 반복 / 랜덤 반복 / 한 곡 반복 지원
- 기존 재생목록/프로필/기본 미디어 폴더 구조 유지
- V3.60에서 발생하던 숨겨진 btnRepeat 참조 오류 수정

주의
- 음악/MP4 원본은 앱 저장소로 복사하지 않습니다.
- iPhone Safari/PWA 환경에서는 원본 파일 권한이 다시 필요할 수 있습니다.
