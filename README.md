말구씨 음악 앱 V3.42 — 음악 커버를 iPhone 잠금화면에 표시

V3.41에서는 잠금화면 MediaMetadata artwork에 앱 아이콘만 사용했습니다.
V3.42에서는 MP3/M4A 등에 포함된 앨범 커버를 먼저 추출해:
- 앱 안의 앨범 이미지
- iPhone 잠금화면/제어센터의 Now Playing 이미지
에 동일한 커버를 사용합니다.

커버가 파일에 포함되어 있지 않거나 추출할 수 없는 경우에만 말구씨 앱 아이콘으로 대체합니다.

중요:
- 원본 음악 파일은 앱 저장소에 복사하지 않습니다.
- 커버 이미지는 현재 세션의 메모리에서만 사용합니다.
- 기존 백그라운드 재생, 이전/재생/다음, MP4 영상/PiP 기능은 유지합니다.
