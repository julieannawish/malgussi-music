# 말구씨 음악 앱 V3.63

## 이번 수정
- 재생목록 `추가`를 누를 때마다 새 파일 선택기를 호출하고 이전 선택 상태를 초기화
- 삭제 후 다시 추가해도 파일 선택이 다시 동작하도록 수정
- MP3/MP4 내장 앨범커버를 재생목록 추가 화면의 썸네일에 표시
- MP4의 iTunes/QuickTime `covr` 커버 추출 수정
- MP4 커버가 없으면 영상 첫 프레임을 잠금화면/미디어 세션 이미지로 사용
- MP3 커버가 없으면 말구씨 앱 아이콘 사용
- 첫 파일을 새 재생목록에 추가하면 즉시 현재 미디어로 로드하여 기본화면 재생 버튼이 동작하도록 수정
- 빈 재생목록의 기본화면은 지정한 강아지 그림 유지
- 앱 버전/서비스워커 V3.63

## 기본 점검
- JavaScript 전체 구문 검사 통과
- MP3 내장커버 추출 테스트 통과
- MP4 `covr` 내장커버 추출 테스트 통과
- 재생목록 추가 후 현재 미디어 로드 경로 점검
- 삭제 후 재추가 시 선택 상태 초기화 경로 점검
- 압축 내부 최상위 파일 구조 점검
