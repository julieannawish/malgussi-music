말구씨 음악 앱 V3.27 — 최근 폴더 기억 UX

- 최근 폴더 이름/파일 수/선택 시각만 저장합니다.
- 음악 File/Blob 자체는 localStorage/IndexedDB에 저장하지 않습니다.
- 원본 다시 연결을 누르면 별도 확인 화면 없이 바로 폴더 선택창으로 진입합니다.
- iOS 18.4+의 webkitdirectory 폴더 선택을 사용합니다.
- 선택된 폴더의 음악을 재생목록과 자동 매칭합니다.
- 다른 폴더를 선택하면 최근 폴더 메타데이터를 갱신합니다.
- 웹 보안상 PWA가 iPhone의 임의 로컬 폴더를 사용자 동작 없이 다시 읽는 기능은 보장되지 않으므로 구현하지 않았습니다.
