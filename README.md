말구씨 음악 앱 V3.52 — 파일관리/재생목록 구조 개편

- 기본 미디어 폴더 지정은 설정에서만 수행
- 기본 폴더의 전체 미디어와 재생목록을 분리
- 새 파일은 자동으로 재생목록에 추가하지 않음
- 폴더를 다시 확인하면 없는 재생목록 파일을 자동 삭제
- 순서 반복 / 랜덤 반복 / 한 곡 반복
- 재생목록 다중 선택 / 일괄 삭제 / 선택 묶음 드래그 순서 변경
- MP3: 앨범커버가 있으면 사용, 없으면 프로필 이미지
- MP4 잠금화면/미디어 세션: 내장 커버 → 첫 프레임 → 프로필 이미지
- 본 앱 MP4 화면은 영상 하나만 표시
- 설정에서 프로필 사진/이름/문구 변경 가능
- 기본 프로필은 사용자가 지정한 아버지 그림을 그대로 사용
- Media Session 이전/재생/다음, PiP, AirPlay 지원 환경 대응

주의: iPhone Safari/PWA는 외부 파일 폴더 권한의 영구 복원이 브라우저 구현에 좌우됩니다. 저장된 폴더 핸들을 복원할 수 있는 환경에서는 재실행 시 자동 재연결을 시도하고, 그렇지 않은 환경에서는 원본을 앱에 복사하지 않기 때문에 폴더를 다시 선택해야 할 수 있습니다. 완전한 무재선택 자동 연결을 100% 보장하려면 네이티브 iOS 앱 구조가 필요합니다.
