# 말구씨 음악 앱 V3.21

GitHub Pages 루트에 아래 파일을 그대로 올리면 됩니다.

- `index.html`
- `manifest.webmanifest`
- `sw.js`
- `dog_default.png` — 음악이 없거나 앨범 커버를 읽지 못할 때 기본 화면
- `app-icon.png` — iPhone 홈 화면용 아버지 그림 아이콘
- `app-icon-192.png` — 작은 아이콘/파비콘

## 주요 기능

- iPhone PWA
- 음악 파일 자체를 앱 저장공간에 복사하지 않는 인덱스 방식
- 여러 곡을 한 번에 원본 연결
- 기존 목록과 파일명/크기/수정일을 기준으로 자동 매칭
- MP3 ID3 APIC, M4A/MP4 `covr` 앨범 커버를 현재 재생 곡에서 임시 추출
- 커버가 없거나 읽지 못하면 강아지 기본 이미지 표시
- 재생목록 세로 스크롤
- 일반 스와이프는 스크롤, 약 0.42초 길게 누르면 순서 드래그
- 이전/재생/다음/계속 듣기

## 주의

앨범 커버는 원본 음악 파일에서 현재 곡을 재생할 때 임시로 읽습니다. 음악 파일 자체나 커버 이미지를 앱의 영구 저장소에 저장하지 않습니다.
