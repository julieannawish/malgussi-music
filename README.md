# 말구씨 음악 앱 V3.71

V3.71 주요 수정
- 재생목록 관리에서 + 추가 후 선택한 파일이 즉시 재생목록 관리 목록에 반영되도록 수정
- 기본화면 미디어 영역을 하나의 고정된 반응형 프레임으로 구성하여 MP3/MP4 전환 시 화면 분리 및 화면 넘침 방지
- 휴대폰 화면 높이에 맞춰 재생/이전/다음/재생목록 버튼이 항상 보이도록 기본 화면 높이 계산 수정
- 재생목록 관리의 상단/재생방식/하단 액션 고정 및 목록만 스크롤


## V3.73 변경
- MP4 영상은 미디어 프레임을 최대한 채우도록 `object-fit: cover` 적용
- MP4 표시 상태에서 미디어 스테이지를 video-mode로 구분
- 기본화면 하단 재생 컨트롤이 계속 보이도록 기존 반응형 구조 유지
