말구씨 음악 앱 V3.29 — 없는 원본 자동 정리

핵심 UX:
- 재생목록을 열었을 때 원본 연결 필요를 일괄 표시하지 않습니다.
- 기존 인덱스는 앱 시작 시 보존합니다. File 객체가 없다는 이유만으로 곡을 삭제하지 않습니다.
- 실제 음악 폴더를 사용자가 한 번 확인하면 그 순간에만 인덱스와 실제 파일을 비교합니다.
- 찾은 곡은 자동 연결합니다.
- 폴더에서 찾지 못한 곡은 재생목록 인덱스에서 자동 삭제합니다.
- 삭제된 원본을 다시 넣고 폴더를 확인하면 새 인덱스로 다시 추가할 수 있습니다.
- 재생/곡 선택 시 원본이 현재 연결되지 않았으면 일반 파일 선택이 아니라 폴더 자동 확인 흐름으로 들어갑니다.
- 음악 파일 자체는 앱 저장소에 복사하지 않습니다.
- 기존 playlist_index_v321 저장 키는 기존 사용자 데이터를 위해 유지합니다.
