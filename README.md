# 말구씨 음악앱 V3.98

V3.98은 V3.97에서 확인된 기본 재생/MP4 문제를 보완하고, 재생목록의 현재 재생 위치 표시와 재생 방식의 사용자 용어를 정리한 버전입니다.

## 이번 버전
- 최초 실행 이전/재생/다음 버튼의 초기화 경로를 회귀 보호합니다.
- MP3 → MP4 전환 시 실제 video `playing` 상태를 확인한 뒤 외부 컨트롤을 `잠시멈춤`으로 표시합니다. iOS 자동재생 제한 시 재생 가능 상태 확인 후 muted fallback을 시도합니다.
- 재생목록 관리에 들어가면 현재 재생 곡을 화면 중앙 부근으로 자동 스크롤하고 `▶ 현재 재생` 하이라이트를 표시합니다.
- 선택 상태와 현재 재생 상태를 서로 다른 시각 상태로 표시합니다.
- `순서 반복`을 `연속재생`으로 일반화했습니다. 기존 `none` 값은 `order`로 마이그레이션하며 기본값은 연속재생입니다.
- V3.90에서 PASS된 `재생목록 → + 추가 → iPhone 파일 선택창` 동작은 변경하지 않습니다.

## 회귀 보호
- V3.97 최초 실행 기본 3개 버튼 PASS 기준
- V3.90 재생목록 + 추가 iPhone 파일 선택
- MP4 프레임 기본 controls/time scrubber 제거
- 재생목록 진입 중 MP4 자동재생 금지
- 기본 화면 복귀 시 MP4 자동재생

## 자체 점검 기준
- HTML/JavaScript 문법
- ID 중복
- 버전 문자열(APP_VERSION/앱 표시/manifest/Service Worker/README) 일치
- 재생목록 현재곡 자동 스크롤/하이라이트 코드 경로
- 연속재생 기본값 및 legacy 값 마이그레이션
- MP3→MP4 autoplay 코드 경로 및 실제 `playing` 이벤트 기준 상태 동기화
- ZIP 무결성

실제 iPhone/iOS Safari의 파일 권한과 미디어 자동재생 정책은 이 환경에서 100% 재현할 수 없으므로, 해당 부분은 코드 경로와 상태 전이를 우선 검증하고 최종 실기기 리뷰 대상으로 남깁니다.
