# 말구씨 음악앱 V3.96

V3.90의 재생목록 + 추가(iPhone 파일 선택) 기능을 보존하고 MP4 자동재생/내부 실행 버튼 동작을 보완한 버전입니다.

## 핵심 동작
- 기본 미디어 폴더는 설정에서 최초 지정하며, 재생목록 추가 과정에서는 이 폴더를 탐색 기준점으로 사용합니다.
- 재생목록 관리의 `＋ 추가`는 V3.68 방식으로 iPhone 파일 선택창을 직접 호출합니다.
- 선택 화면에서는 최상위 기본 미디어 폴더 아래의 하위 폴더를 계속 탐색할 수 있습니다.
- `‹ 상위 폴더`와 상단 경로 버튼으로 기본 미디어 폴더 내부에서 이동할 수 있습니다.
- 파일을 선택한 뒤 `재생목록에 추가`를 누르면 원본 파일을 이동/복사하지 않고 재생목록에 참조로 추가합니다.
- 추가 완료 후 재생목록으로 돌아오며 성공 메시지와 방금 추가한 항목 위치 자동 스크롤/하이라이트를 제공합니다.
- 기본 미디어는 설정의 폴더 지정 기능으로만 노출되며 구형 별도 기본 미디어 관리 화면은 재생목록 흐름에서 사용하지 않습니다.

## 재생목록 기능 보존
- 곡 클릭 재생
- 멀티셀렉트/연속 선택
- 선택 안내문구
- 추가 / 삭제 / 중복 삭제
- 선택 항목 묶음 드래그 순서 변경
- 반복 안 함 / 순서 반복 / 랜덤 반복 / 한 곡 반복
- 재생목록 자체 세로 스크롤

## MP4 기능 보존/점검
- MP4 전용 영상 영역으로 전환하며 MP3 이미지와 동시에 보이지 않도록 합니다.
- 영상의 실제 종횡비를 기준으로 화면 안에 맞춰 표시하고 잘라내지 않습니다.
- playsinline / webkit-playsinline 적용
- 사용자 재생 버튼에서 MP4 재생
- 반복 모드에 따른 MP4 종료 후 다음 곡 자동 재생
- MP4 커버 우선순위: 내장 커버 → 영상 첫 프레임 → 땡콩이
- MP3 커버 우선순위: 앨범커버 → 땡콩이

## 점검 항목
- HTML/JavaScript 문법 검사
- ID 중복 검사
- 재생목록 추가 버튼 이벤트 연결 검사
- 파일 탐색/하위 폴더/상위 폴더 경로 로직 검사
- 추가 후 목록 복귀/메시지/자동 스크롤 검사
- 재생목록 스크롤 CSS 검사
- MP4/MP3 전환 시 artwork/video 상호 배타 표시 검사
- MP4 화면 종횡비 자동 맞춤 코드 검사
- MP4 ended → 반복 모드별 다음 재생 경로 검사
- 버전 문자열/manifest/Service Worker/README 일치 검사
- ZIP 무결성 검사

## 주의
실제 iPhone의 파일 권한과 iOS Safari/PWA의 미디어 코덱 동작은 데스크톱 정적 테스트만으로 100% 재현할 수 없으므로, 패키지 제공 전 자동화 가능한 브라우저 테스트와 코드 경로 검사를 함께 수행했습니다.


## V3.96 검증 기준
- 재생목록 관리의 재생 방식 버튼은 유지합니다.
- 재생목록 관리의 추가/삭제/중복 삭제를 유지합니다.
- + 추가는 음악/영상 필터 화면이 아니라 탐색기형 폴더 선택 화면으로 엽니다.
- 기본 미디어 최상위 폴더에서 시작하며 하위 폴더와 상위 폴더를 탐색할 수 있습니다.
- 파일 선택 후 재생목록에 추가하고 추가 완료 메시지와 자동 스크롤을 제공합니다.
- MP4 전용 영상 화면, 화면 맞춤, 자동재생/다음곡 전환을 유지합니다.

## V3.96 변경 기준
- 재생목록 관리의 `＋ 추가` 동작만 V3.68의 검증된 native iOS 파일 선택 방식으로 복원했습니다.
- `＋ 추가` 클릭 시 앱 내부 파일 목록/탐색 화면을 거치지 않고 iPhone 파일 앱이 즉시 열립니다.
- 선택한 MP3/MP4는 선택 완료 후 즉시 재생목록에 반영됩니다.
- 기존 재생목록/재생/반복/MP4 관련 기능은 수정 범위에서 제외했습니다.
