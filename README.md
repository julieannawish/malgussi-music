# 말구씨 음악앱 V3.78

이번 버전은 이전 기능을 유지하면서 다음 문제를 수정한 회귀점검본입니다.

- 재생목록에서 파일 추가 후 같은 화면에 즉시 목록 반영
- MP4 첫 재생 시 실제 play() 성공 여부와 앱 재생상태 동기화
- MP4가 실제 정지인데 앱 버튼이 일시정지로 남는 상태 불일치 방지
- 왼쪽 선택 버튼을 쓸어 연속 다중선택할 때 화면을 재렌더링하지 않아 터치가 끊기지 않도록 수정
- 오른쪽 ≡ 영역을 빠르게 쓸어 지나간 곡들이 자동 다중선택되도록 유지
- 선택된 곡은 동일한 선택색으로 표시
- 길게 누른 뒤 드래그하면 선택된 곡 묶음을 함께 이동
- 중복 삭제는 재생목록 항목만 제거하고 원본 파일은 삭제하지 않음
- 저장된 기본 미디어 폴더/캐시로 재생목록 원본을 재연결
- 재생목록에 새 파일을 추가할 때 기존 캐시 파일을 지우지 않고 누적 보존
- MP4는 원본 비율을 유지하고 잘리지 않게 최대 크기로 표시
