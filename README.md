# 말구씨 음악앱 V3.99

V3.99는 V3.98 이후 확인된 재생 컨트롤 간헐적 미동작, 기본 미디어/재생목록 동기화, 현재 재생곡 표시, 재생 방식 UI, 상태 메시지 문제를 보완한 버전입니다.

## 핵심 변경
- 초기화면 3종 세트(이전/재생·잠시멈춤/다음)의 중복·경쟁 실행 방지
- 현재 미디어가 이미 연결된 경우 사용자 탭을 바로 처리하도록 부팅 대기 의존 최소화
- MP3→MP4 전환에서 실제 재생 상태와 외부 버튼 상태를 분리
- MP4 프레임 내부 기본 컨트롤/시간바 제거 유지
- 재생목록 진입 시 현재 재생곡 자동 스크롤 및 하이라이트 유지
- 재생 방식 3개를 균등 배치하고 `연속재생`을 기본값으로 유지
- 기본 미디어 폴더의 하위 폴더까지 재귀 탐색
- 검증된 폴더 스냅샷과 재생목록을 동기화하여 원본이 확인되지 않는 항목 정리
- 정상 재생목록 상태에서 오래된 `음악 폴더를 선택해 주세요.` 메시지가 남지 않도록 상태 메시지 정리
- 앱/Manifest/Service Worker/README 버전 V3.99 일치

## 기존 기능 보호
- V3.90 기준 `재생목록 → 추가 → iPhone 파일 선택/폴더 탐색` 흐름 유지
- 기존 멀티셀렉트, 삭제, 중복삭제, 순서 변경 기능 유지
- 기존 MP4 프레임 레이아웃 유지

## 주의
실제 iPhone의 Safari/PWA 자동재생 정책과 Files 권한은 개발 환경에서 완전 재현할 수 없으므로, 이 패키지의 자체 테스트는 코드/DOM/상태전이/패키징 및 Chromium 기반 회귀 점검을 포함합니다.
