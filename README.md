# 말구씨 음악앱 V3.76

기존에 테스트·확정한 V3.74/V3.75 기능을 유지하고, 오른쪽 ≡ 영역의 빠른 다중선택 동작을 추가한 버전입니다.

## 핵심 기능
- MP4: 원본 비율 유지, 영상 크롭 없음, 프레임 안에서 가능한 최대 크기로 표시.
- 기본 미디어 폴더: 한 번 지정한 폴더의 파일을 앱 재실행 후에도 IndexedDB 미디어 캐시 또는 허용된 폴더 핸들로 자동 연결.
- 재생목록: 추가 / 선택 삭제 / 중복 삭제 / 다중 선택 / 묶음 순서 변경.
- 중복 삭제: 같은 파일명 + 파일 크기가 같은 중복 항목은 첫 번째 항목을 남기고 나머지를 재생목록에서 삭제하며 원본 파일은 삭제하지 않음.
- 오른쪽 ≡ 빠른 선택: 오른쪽 ≡ 영역을 빠르게 위·아래로 쓸면 지나간 곡의 선택 상태가 자동으로 켜져 하나의 선택 그룹이 됨.
- 오른쪽 ≡ 길게 누른 뒤 드래그: 현재 선택된 곡들을 하나의 그룹으로 이동.
- 현재 재생곡과 관리용 선택 상태는 서로 분리.
- 재생방식: 반복 안 함 / 순서 반복 / 랜덤 / 한 곡 반복.
- MP3 ↔ MP4 연속재생 및 현재곡 복원.
