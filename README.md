# 말구씨 음악 앱 V3.54

- 기본 미디어 폴더 지정은 설정에서만 수행
- 초기 화면의 직접 음악 넣기 버튼 제거
- 재생목록 관리에서 기본 미디어를 선택해 원하는 파일만 추가
- 순서 반복 / 랜덤 반복 / 한 곡 반복
- 재생목록 다중 선택, 일괄 삭제, 선택 항목 묶음 드래그 순서 변경
- 폴더에서 사라진 재생목록 항목은 실제 폴더 스캔 후 자동 정리
- MP3/MP4 재생 및 백그라운드/잠금화면 Media Session 유지
- 프로필 사진, 이름, 문구를 설정에서 직접 변경 가능
- 기본 프로필 이미지와 강아지 이미지는 현재 패키지에 포함된 파일 사용
