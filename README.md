# 말구씨 음악앱 V3.80

전체 기능 회귀 점검본.

- 사용자 터치에 의한 재생은 iPhone Safari의 사용자 활성화가 유지되는 즉시 `play()` 호출
- 재생목록 추가 즉시 반영
- 기본 폴더/파일 캐시 복원
- 중복 삭제 및 원본 파일 보존
- 왼쪽 선택 버튼 다중선택 + 오른쪽 `≡` 빠른 연속선택
- 선택 그룹 드래그 이동
- 재생목록 중앙 영역 스크롤 및 진입 시 현재 재생곡 자동 위치
- 반복 안 함 / 순서 반복 / 랜덤 반복 / 한 곡 반복
