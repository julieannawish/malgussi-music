# 말구씨 음악앱 V3.95 QA

## 목적
V3.94에서 남아 있던 최초 실행 시 기본 화면 이전/재생/다음 버튼의 지연 문제를 수정했습니다.

## 핵심 수정
- 앱 부팅 시 저장된 파일 재연결 과정에서 대용량 artwork 추출을 기다리느라 `appBootReady`가 늦게 완료되던 경로를 fastBoot로 분리했습니다.
- 최초 화면의 재생 컨트롤 준비는 미디어 소스 연결과 UI 상태 초기화까지만 먼저 완료합니다.
- artwork 분석은 최초 컨트롤 준비 이후의 보조 작업으로 처리할 수 있도록 기존 구조를 보존했습니다.
- V3.90에서 PASS된 `재생목록 관리 → + 추가 → iPhone 파일 선택창`은 변경하지 않았습니다.
- MP4 자동재생/프레임 상태/재생목록 진입·복귀 정책은 V3.94 기준을 유지했습니다.

## 자체 점검
- APP_VERSION V3.95 일치
- manifest/sw 버전 V3.95
- relinkFromFolder fastBoot 인자 연결 확인
- 최초 부팅 경로에서 fastBoot=true 사용 확인
- +추가 picker 호출 코드 변경 없음 확인
