# 말구씨 음악앱 V3.95

## 이번 버전 범위
V3.93을 기준본으로 하고, 기존 PASS 기능은 유지하면서 최초 실행/기본 재생 초기화와 MP4 상태 표시, 재생방식 기본값의 안정성을 보완했습니다.

## 수정 사항
- 앱 최초 실행 시 저장된 재생목록의 현재 파일 연결과 기본 화면 재생 컨트롤 준비를 빠르게 완료하도록 부팅 경로를 최적화했습니다. 대용량 artwork 분석은 최초 컨트롤 초기화를 막지 않도록 지연합니다.
- 재생 방식 값이 비정상/구버전 값이면 `반복 안 함`으로 정규화하고 반드시 하나가 선택되도록 했습니다.
- MP4에 대한 iOS 기본 video controls를 명시적으로 비활성화했습니다.
- MP4 재생 이벤트에서 프레임 내부 `실행` 오버레이와 외부 `재생/잠시멈춤` 상태를 동기화하는 기존 V3.92/V3.93 동작을 보존했습니다.
- 재생목록 관리 화면 진입 시에는 MP4 자동재생하지 않고, 기본 화면으로 복귀할 때만 자동재생하는 V3.93 정책을 유지했습니다.
- V3.90에서 PASS된 `재생목록 관리 → + 추가 → iPhone 파일 선택창` 흐름은 변경하지 않았습니다.
- Service Worker/manifest 버전을 V3.95로 갱신했습니다.

실제 iOS 파일 앱 호출, iOS 권한, 실제 MP4 자동재생 정책 및 터치 입력은 이 개발 환경에서 실기 검증할 수 없으므로 사용자 실기 확인이 필요합니다.
